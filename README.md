# Wasla App

A modern, Uber-inspired service booking app concept built with Next.js and Tailwind CSS.

## Features
- Location-based service discovery
- Nearby driver cards
- Request trip summary
- Booking dashboard
- Fast service categories
- Minimal, premium mobile-app styling

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
This is a polished frontend MVP designed to mimic the feel of a ride-service app while staying original.
